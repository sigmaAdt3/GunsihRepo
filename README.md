# GunIsh Jewels Website

Static HTML/CSS/JS jewellery storefront ready for GitHub Pages.

## Before publishing
1. Replace the images in `images/banners/` and `images/products/` with your real jewellery photos.
2. Open `script.js` and update `whatsappNumber` if needed.
3. Edit the `products` array in `script.js` to add/remove products.
4. Push the project to a GitHub repository on the `main` branch.
5. In GitHub: Settings → Pages → Source → GitHub Actions.

## Features
- Premium responsive design
- Hero banner and logo
- Collection categories
- Search and category filters
- Product detail popup
- Quantity selector
- WhatsApp ordering
- Mobile menu
- GitHub Pages workflow

## Custom domain
After deployment, use Repository → Settings → Pages → Custom domain and configure DNS at your domain registrar.
